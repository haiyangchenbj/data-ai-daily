一、行业叙事主线：半年演变脉络

1.1 月度主线

5 月：Agent 原生架构从概念验证进入产品发布。 SAP、腾讯云、Starburst、dbt、Databricks、Snowflake、Google Cloud、Microsoft 同月以不同路径发布 Agent 可操作的数据平台能力，MCP 从"有前景的开放协议"升级为数据基础设施的事实标准控制面。Google Cloud Next 与 Microsoft Build 两场峰会以 60+ 项公告完成全栈 Agent 化。国内政策与产品共振：国家数据局将"数据赋能 AI"列为年度工作要点独立板块，信通院发布模数共振报告。

6 月：双峰会定调，Agent 化成为产品矩阵核心叙事。 Snowflake Summit 26 提出 Agentic Enterprise，Databricks DAIS 发布 LTAP 架构。竞争维度从"谁存的数据多"切换为"谁能让 Agent 更可靠地操作数据"。开放表格式从对抗走向融合：Databricks 将 Delta Sharing 升级为 OpenSharing 并捐赠 Linux Foundation，Snowflake 以 Iceberg v3 GA + Polaris 双向 Catalog 完整回应。治理边界从数据权限延伸到 Agent 运行时（能做什么、花多少钱）。

7 月：治理战场移至跨平台互操作层，AI 能力独立商业化。 MCP 2026-07-28 规范发布（无状态核心、统一能力发现、全链路追踪），Databricks Unity AI Gateway 成本治理 GA，Snowflake 在 Black Hat 发布 Cortex AI Gateway。Databricks Genie 全线切换按量付费，数据平台的 AI 能力从附赠功能升级为独立产品线。资本端出现估值重定价：Airtable 较峰值折价 89% 出售、Domo 折价 87%，独立 BI/数据平台的退出路径从 IPO 转向被整合。

8 月：叙事收敛到工程细节。 厂商围绕 Agent 的运行需求打磨数据库状态与分支（Databricks 收编 Electric 团队、阿里云 PolarDB Agentic Database 公测）、代理身份、模型路由与成本归因。多数能力处于公测/Beta/灰度阶段，生产验证普遍缺位。发布密度本身构成信号：客户在追问账单与质量。

9 月：从"连上模型"转向治理与运行时。 Agent 凭据托管、注册表、会话治理相继 GA 或预览（Databricks Genie One MCP GA、Google Agent Registry、MongoDB Atlas Agent Engine、Microsoft Fabric 多个 MCP Server 批量 GA）。开放湖仓成为默认数据接口：Redshift 支持 Iceberg v3，Aurora PostgreSQL 直接查询 Iceberg 与 Parquet，运营数据库与湖仓边界开始融合。检索与上下文从外挂组件转为平台内置（AlloyDB/Cloud SQL 原生 BM25）。二级市场开始按 AI 收入兑现度分化定价：Snowflake 产品收入 +37% 盘后涨 23%，MongoDB 营收 +30% 盘后跌 14%。

10 月：叙事收敛为"数据平台 = Agent 运行时"。 Databricks 与 Snowflake 用几乎相同的四件套完成重构：记忆（Agent Memory / Compact API）、执行运行时（AI Runtime / Cortex 代码执行）、治理网关与可观测（Unity AI Gateway / Cortex AI Gateway + Agent Observability）、语义层（Genie Ontology / Semantic Studio GA）。语义层的标准之争开场：微软与 Snowflake 共推 Apache Ossie 语义交换规范。Gartner IT Symposium 定调"AI 风险增速超过价值，智能体治理缺口成首要议题"；IDC 指出 AI 基础设施的约束已从需求侧转到供给侧。

1.2 六条贯穿主线

二、厂商核心故事

2.1 Databricks

核心叙事：Data Intelligence Platform 重构为 Agent 运行时与多 AI 治理平台。

  • 架构层：LTAP（Lake Transactional/Analytical Processing）在存储层统一事务与分析，Lakebase（serverless Postgres，源自 Neon）承接 Agent 沙箱与分支数据库，Lakehouse//RT 提供亚 100ms 实时分析（厂商口径 12,000 QPS）。
  • Agent 层：Genie One 连接 50+ 办公应用、可在隔离沙箱执行代码（沿用调用者权限）；Agent Bricks 作为构建与治理单一控制点；10 月发布 Agent Memory（MemCurrent 架构：情景记忆+派生记忆+离线归并，厂商自测 114 项企业任务完成率 22.3% → 68.4%，token -31%，未经第三方复现）。
  • 治理层：Unity AI Gateway（硬性支出上限、智能路由、上下文策略），LLM 端点纳入 Unity Catalog。
  • 开放层：OpenSharing 捐赠 Linux Foundation，Unity Catalog Iceberg 全面 GA。
  • 关键数字：年化收入超 70 亿美元（+80%），AI 产品年化超 17 亿美元；8 月完成 50 亿美元融资，估值 1900 亿美元；平台上已构建超 10 万个 Agent、年处理超千万亿 token（均为官方披露）。
  • 市场反应：半年两轮共 80 亿美元私募，明确 2026 年不上市。CEO Ghodsi 坦言 Agent 大规模上线后毛利率下行，消费型计费的结构性压力是全行业共同挑战。
  • 注意：LTAP 与 Lakebase 的生产级客户案例、独立基准仍未公开；所有关键性能与成功率数字为厂商自测。

2.2 Snowflake

核心叙事：AI Data Cloud 升级为 Agentic Control Plane，10 月收敛为 Agentic Analytics 框架（Ground / Analyze / Act + Assure 治理层），主张"控制随数据走"，反对把数据复制进每一个 AI 平台。

  • 叙事前提：模型是租来的，意义是自己的。企业 AI 的瓶颈不在模型而在上下文。上下文阶梯：直连 SQL 24.1% → 加语义模型 47.1% → 加治理上下文 86.3%；单次提问成本 $1.76 → $0.59（厂商口径，测试条件未披露）。
  • 产品更名：Snowflake Intelligence → CoWork（业务用户），Cortex Code → CoCo（开发者）。话术："CoCo builds the agent. CoWork puts it to work."
  • 上下文层：业务本体并入 Horizon Context；Semantic View GA 进 IDE（Semantic Studio）；边界明确——只在 Snowflake 内可见、不原生供给外部 BI 工具、无跨账户复制。
  • 治理层：Cortex AI Gateway（收购 Natoma 获得的 MCP 网关能力，模型路由/身份/策略/审计/预算上限，支持 100+ MCP 服务器）；AI Agent Identity GA（每个 Agent 独立身份与审计轨迹）；Agent Observability 进入 Private Preview（OpenTelemetry 兼容，LLM-as-judge 在线评估）。
  • 数据层：全面拥抱 Iceberg v3；Snowflake Postgres 与 Postgres 数据镜像 GA，运营库与分析库同平台。
  • 关键数字：FY27 Q2 产品收入 +37% 连续三季加速，盘后涨 23%；RPO 92.1 亿美元（+38%）；NRR 126%；CoWork 企业用户 5,000+、CoCo 9,000+；10 月完成 37.5 亿美元零息可转债，资金明确指向并购与战略投资。
  • 中国区：授权运营形态（AWS 宁夏区域、神州数码云科技全权运营、独立域名），跨组织数据共享网络与数据市场在境内不开放；实际客群为跨国企业在华机构与中国出海企业。World Tour 上海站为全球叙事的完整平移，无中国区专属产品。
  • 11 月 3-6 日 Expedition 2026 全球大会以 agentic transformation 为主轴，微软 CEO Nadella 站台。

2.3 AWS

核心叙事：不抢"Agent 平台"口号，把开放湖仓做成所有引擎的默认接口，并把数据工程 Agent 限定在构建期。

  • 开放格式下沉：Glue 6.0 GA（Spark 4.1 完整支持 Iceberg v3，官方称降价 30%）、Redshift 支持 Iceberg v3 并自动消解并发写冲突、Aurora PostgreSQL 直接查询 Iceberg/Parquet 数据湖、MSK 原生集成 Iceberg 流表写入、S3 Tables 支持 Iceberg v3 数据类型。开放表格式从分析层下沉为流数据与运营库的默认着陆层。
  • Agent 路径：Amazon Quick 自主 Agent（6 月）；ADOP 参考架构（8 月）明确数据工程 Agent 在构建期生成可审查产物（PySpark/SQL/Airflow DAG），经 CI/CD 部署到生产，模型不直接接管生产管道。这是三大云中对 Agent 生产责任边界最保守也最清晰的表述。
  • 生态动作：签署收购 DuckLabs 最终协议（DuckDB 保持独立基金会治理）；与 Snowflake 五年 60 亿美元算力协议。
  • 隐含判断：当所有厂商都在讲 Agent，AWS 在讲格式、价格和工程确定性，竞争落点在迁移成本与运维信任。

2.4 Google Cloud

核心叙事：Agentic Data Cloud——borderless lakehouse + Knowledge Catalog 整合为 Agent 的单一行动系统。

  • 交互层：BigQuery Conversational Analytics GA（5 月 Next '26），自然语言对话数仓成为标配；Continuous queries GA，数仓从批处理快照进化为实时引擎。
  • Agent 层：Data Engineering Agent GA、托管 MCP Servers for Databases GA、Agent Registry（凭据与身份托管）；10 月将开放 Iceberg 表的联邦目录扩展到 Databricks、Snowflake、AWS 三家，并让 Gemini 直接查询竞对目录数据；11 月 4 日定档 Agentic Data Cloud 专项活动。
  • 数据库层：AlloyDB 面向 Agent 的沙箱实例（秒级拉起、按需归零）、原生 BM25 混合检索、向量索引内存缓存；BigQuery Graph GA 支持跨云原地遍历；TimesFM 3.0 时序基础模型入仓。
  • 策略特征：以跨云、跨目录互操作作为差异化，把"开放"做成对 Databricks/Snowflake 锁定叙事的对冲。引用口径：83% 组织需升级基础设施以支持 Agentic AI（厂商调研）。

2.5 微软

核心叙事：Fabric 全栈 Agent 化 + 语义标准的中立推动者。路线本质是把 Agent 化打包进既有订阅，与 Databricks/Snowflake 的 AI 能力独立计价形成对照。

  • Build 2026 以约 60 项公告完成数据平台全栈 Agent 化：Fabric Data Agent（自然语言问答组织数据）、Real-Time Intelligence、OneLake Security GA。9 月 Fabric IQ MCP Server、Core MCP Server 与 Data-agent MCP 任务批量 GA，Fabric IQ 进入 Microsoft 365 Copilot。
  • 数据库：Azure HorizonDB 与 DocumentDB 并列布局；开源 PostgreSQL 运维智能体（告警变答案）。
  • 标准层：与 Snowflake 共同承诺 Apache Ossie，把语义元数据交换推向厂商中立标准，Google 随后加入（仍处孵化期）。
  • 分析师评价：Forrester Data Fabric Wave Q4 2025 领导者（愿景聚焦"统一、智能、Agentic 的 Data Fabric"）；Futurum Signal 指出 OneLake 乐观并发写瓶颈造成技术失分。
  • 策略特征：订阅打包路线的另一面是 AI 用量不透明，Fabric 未提供 Agent 粒度的成本归因能力，这恰是客户焦虑 3（预算失控）的对应缺口。

2.6 阿里云

核心叙事：Agentic Cloud——"按 Agent 重构云"，全栈四层（芯片-云-模型-推理）+ 千问云入口；大数据条线收敛为"AI 原生数据底座"。

  • 5 月峰会：自我定位"国内云厂商首次围绕 Agent 进行全栈产品发布"，Agent Infra 六大能力域 32 项新品，数据平面占 10 项（条目最多）。商业故事：百炼 Token 日均收入 5 个月 +15×，MaaS 收入将取代 ECS 成为最大产品线（厂商口径）。
  • 概念框架：李飞飞给出 AI Native 数据库判断标准——"一半实例是 Agent 在使用，一半输出 Byte 是 Token"，并明确把自己放在"AI Ready → AI Native"演进路径上，不抢 AI Native 用词。承诺年内所有云产品完成 Skill/MCP/CLI 三件套控制面改造。
  • 大数据条线：DataWorks Data Agent（自然语言全流程接管数据开发，淘宝闪购单需求 12-23 小时压缩至 5-10 分钟，客户口径）；OSS Table Bucket（对象+向量+表格三桶多模底座，表格桶集成 Iceberg 语义）；引擎集体升级（MaxCompute AI Function、Hologres 向量双榜第一、ES falls seek 引擎性能 2-6×，均厂商口径）。
  • 9 月云栖大会：首推 AI 原生大数据服务 ADA（多智能体协同架构，统一对话入口调用离线/实时/流式/训推/搜索引擎）；OpenLake 迈向 Agentic Lake；Flink Streaming Agent；Hologres 优化器四个月自主完成 28 项优化（厂商口径）；李飞飞提出 Context Engine 概念（产品化状态待确认）。同期宣布全球基础设施扩建（土耳其、芬兰、荷兰新节点）。
  • 开源与社区：FFA 2026 发布 Flink 3.0 规划（Agentic Streaming）、Paimon 2.0（Agentic Lake）、Fluss 1.0（Agent 实时上下文层，已升 Apache 顶级项目）。王峰（阿里云开源大数据负责人）：“Agent 能否高质量落地，既取决于模型能力，更依赖于数据质量和效率。”
  • 第三方背书：IDC《中国 Data Agent 2026》评估 18 家入选、4 家领导者，阿里云居首。
  • 注意：性能与商业数字均为厂商口径；ADA/OpenLake/Context Engine 的 GA 节奏与生产案例待官方文档确认。

2.7 火山引擎（字节跳动）

核心叙事：国内对"数据平台服务对象从人变为 Agent"表述最直白的厂商，6 月 Data Agent Pro + AgentDataLake，10 月 Lakebase 库湖一体落地。

  • 6 月：数智平台发布 Data Agent Pro 与 AgentDataLake，Data Agent 从"数据专家"升级为"数字合伙人"，是国内最早一批配套完整产品栈的 Agent 原生数据平台宣言。
  • 10 月 22 日：Lakebase 正式发布——以 PostgreSQL 为事务底座，业务数据一次写入自动生成主流湖仓格式的分析表，统一 Catalog 治理，全程无 ETL 与同步管道；Serverless 存算分离；官方称算力成本可降 90% 以上（厂商口径，需自有负载验证）。选型口径随之改写：比的是智能体获取上下文的端到端成本，不只是查询性能。
  • 配套：LAS AI 数据湖（多模态算子下沉）、DataLeap LeapAgent One、EMR AI 助手接入豆包工作台、TiDB 版公测（交易与向量检索共用一份数据）。
  • 底座支撑：字节跳动 2026 年 AI 资本开支上调至 2000 亿元人民币（+25%），全球 CSP 中增速最快之一。
  • 对位参考：Lakebase 主打"一次写入免 ETL"的库湖一体，我方叙事重心在存-算-调一体与多模态数据湖；现场应答落在两个不同维度——智能体获取上下文的端到端成本、Agent 工作负载的统一调度，避免被拉进"免 ETL"的单点比较。

3.1 Gartner

  • 2026 D&A 八大趋势归入三支柱：智能体（Agentic Data Management / Agentic Data Streaming / Decision Governance）、语义（Composite Semantic Layers / GraphRAG）、平台（融合型数据管理平台 / AI 治理平台 / Sovereign AI）。

3.2 IDC

  • 总定性："AI Is Ready. Enterprises Are Not."——问题不是技术，是 adoption enablement。81% 企业已制定详细 AI 战略，仅 12-16% 实现全企业层面 AI 驱动执行，仅 11% 采用 Agentic AI（2026 年 10 月，15 国 643 家组织）。近 50% 的 AI 用例 2026 年无法达成 ROI 目标。
  • 中国 FutureScape：到 2027 年未优先建设 AI 就绪数据的企业生产力下降约 15%；到 2028 年 60% 的中国 500 强部署企业级 Data Agent；到 2031 年中国企业将拥有 3.5 亿个活跃智能体。
  • 《中国 Data Agent 2026 厂商评估》：18 家入选、仅 4 家进入领导者象限（上一年度 8 家），阿里云居首——供应商选择范围收窄，"选路线"取代"选功能"。
  • 供给侧警告（10/22）：AI 基础设施约束已从需求侧转到供给侧，美国近 7 GW 的 2026 年计划容量因缺电延期或取消，HBM4 供给 2027 年中才追得上需求；数据中心建设周期 5-7 年，加速卡 12-18 个月换代，长约算力定价假设需要重估。
  • 对厂商的要求："不要把数据问题丢回给客户"——数据评估、清洗、结构化应纳入实施过程与验收标准。

3.3 Forrester

  • 2026 是"清算之年"：企业将 25% 的计划 AI 支出推迟到 2027 年；不到三分之一决策者能把 AI 价值与财务增长挂钩。
  • 湖仓 Wave Q3 2026（首份以 Agent 为纲的湖仓评估）：湖仓从分析数据存放地变为 Agentic AI 的执行层；信任（质量/治理/血缘/安全）是基础，开放架构（开放表格式/零拷贝共享）是战略差异项，存储与查询性能已是入场券。Cloudera 获领导者。
  • 语义层报告（6 月）：语义层重新定义为"数据与分析应用的控制平面"。84% 企业已在用语义层平台，但平均每家运行 3 个 BI 平台 + 4 个数据平台，口径互不共享；NL2SQL 受控基准准确率仅 70-80%，真实企业查询更低——对仪表盘是尴尬，对自主行动的 Agent 是危险。
  • 概念贡献：agentlake（位于数据湖旁的智能体层，含共享记忆、MCP/A2A 总线、策略引擎）。

6.1 五条参照建议

  1. "Agent-Ready"踩中了行业共识词汇带。 Gartner（AI 就绪数据）、IDC（Data Readiness 是规模化先决条件）、阿里云（AI Ready → AI Native 路径）、Snowflake（AI-ready data 主轴）使用同一语义场。专场副标题"构建 Agent-Ready 的智能大数据平台"与行业最大公约数对齐，不需再论证概念合法性，应该把篇幅让给"怎么算 Ready、Ready 之后省什么"。
  2. 客户焦虑与专场内容的映射是现成的。 幻觉税与人工复核（焦虑 1）对应数据就绪与语义层能力；数据安全不敢放开（焦虑 2）对应治理与权限体系；预算失控与 Agent 账单（焦虑 3）对应系统智能/成本治理；试点死亡谷（焦虑 4）对应"从能闭环的场景开始"的落地方法论。演讲与客户环节按"焦虑—解法—证据"组织，比按产品功能组织更贴合当前采购心理。
  3. 两个行业级空档可占位。
  • 单位经济学：所有厂商都在做 Agent 成本治理功能，但没有一家给出客户可自己算的账（单个 Agent 任务的端到端成本构成）。谁先把账算清楚，谁就拿到财务问责收紧周期（焦虑 5）的话语权。
  • 语义资产可迁移性：Snowflake 把语义锁在平台内，Ossie 标准刚孵化，Databricks 走开源标准。客户普遍担心语义层投入变成沉没成本（3.5 节分歧 3）。"语义资产属于客户"是此刻对买方有分量的立场。
  1. 需要规避的表述。 厂商叙事中的性能与降本数字几乎全部为厂商口径（阿里云 90% 降本、Databricks 68.4% 完成率、Snowflake 上下文阶梯等），引用他厂数字做对比时必须带口径标注；不使用"首个/唯一"类竞争表达；高密度 Agent 发布中大量能力处于 Preview/Beta，不宜把行业叙事当成已兑现事实来写。
  2. 圆桌与生态环节的外部语境。 IDC 供给侧判断（电力/内存/封装 2027 年前硬约束）与 Gartner"风险增速超价值"定调，意味着大会听众中的 CIO 群体正被要求证明 AI 回报；Physical AI 圆桌的"数据之择"议题（真机/仿真/合成数据）与国家数据局高质量数据集行动（具身智能、智能驾驶在 5 个创新领域内）存在政策呼应，可作为串词素材。
